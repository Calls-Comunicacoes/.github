### O que é o Calls

Um app de comunicação para servidores e grupos de amigos, com identidade própria e infraestrutura no Brasil. Quem cuida das chamadas é o **Callstor**, o castor de headset.

- **Servidores e canais de texto** em tempo real, com convites, cargos e histórico
- **Salas de voz, vídeo e tela** com criptografia ponta a ponta
- **Amigos e calls privadas**, perfis personalizáveis e conquistas
- **Launcher próprio**, que instala e mantém o app atualizado

## Repositórios

| Camada | Repositório | Conteúdo |
|---|---|---|
| Front | `calls-desktop` | App desktop (Electron + React + LiveKit) |
| Front | `calls-launcher` | Instalador e atualizador com canais e rollback |
| Front | `calls-design` | Design system: tokens, componentes React e ícones |
| Front | [`calls-site`](https://github.com/Calls-Comunicacoes/calls-site) | Site de download e prévia web do app |
| Back | `calls-server` | Supabase (banco, auth, realtime, storage, functions) e LiveKit |
| Distribuição | [`calls-releases`](https://github.com/Calls-Comunicacoes/calls-releases) | Instaladores e manifestos de atualização |
| Docs | `calls-docs` | Planejamento, modelo de dados, marca e negócio |

> [!NOTE]
> Parte dos repositórios é privada enquanto o Calls está em alpha. O site, os downloads e os padrões da organização são públicos.
