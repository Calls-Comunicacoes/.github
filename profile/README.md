### 🧱 Como o projeto é organizado

| | Repositório | O que tem |
|---|---|---|
| 🎨 Front | `calls-desktop` | App desktop (Electron + React) |
| 🎨 Front | `calls-launcher` | Launcher de download e atualização |
| 🎨 Front | `calls-design` | Design system: cores, componentes e ícones |
| ⚙️ Back | `calls-server` | Supabase e LiveKit (dados, login, tempo real e voz) |
| 📦 Downloads | [`calls-releases`](https://github.com/Calls-Comunicacoes/calls-releases) | Instaladores e atualizações |
| 📚 Docs | `calls-docs` | Planejamento e identidade visual |
